# About

Awareness-wala is a Python-based WiFi security awareness and auditing toolkit designed for controlled lab environments and cybersecurity learning.

The project demonstrates how common wireless attack workflows operate in practice, helping students and enthusiasts understand:

- WPA/WPA2 handshake capture
- PMKID collection
- Captive portal simulation
- Wireless reconnaissance
- Password auditing workflows

This toolkit is built for awareness, defensive understanding, and educational demonstrations.

---

# Features

- Interactive terminal interface
- Wireless network scanning
- WPA handshake capture
- PMKID attack workflow
- Captive portal simulation module
- Password auditing support
- Rich terminal panels and UI
- Modular Python architecture
- Logging system
- Hashcat integration
- Aircrack-ng integration
